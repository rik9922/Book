# Design System: Modern Heirloom

## 1. Aesthetic Philosophy

Modern Heirloom pairs the warmth, dignity, and permanence of physical bookcraft with high-precision digital ergonomics. It avoids generic tech dashboard conventions (neon gradients, noisy glassmorphism, floating cards with arbitrary shadows) and favors archival restraint, organic textures, editorial typography, and purposeful spatial micro-motion.

## 2. Color Palette & Semantic Tokens

| Token Name | Hex Code | Semantic Role |
| :--- | :--- | :--- |
| `--color-paper` | `#F7F4ED` | Primary background, book page surface, archival warmth |
| `--color-paper-subtle` | `#EFECE4` | Secondary surface, subtle canvas backing |
| `--color-ink` | `#262B2B` | Primary text, high-contrast headings, structure lines |
| `--color-ink-muted` | `#5C6464` | Body secondary, timestamps, metadata captions |
| `--color-forest` | `#304C43` | Primary accent, hardcover spine binding, primary buttons |
| `--color-sage` | `#91A593` | Secondary accent, badges, collaborative markers, tags |
| `--color-clay` | `#C9826A` | Warm focal accent, bookmark ribbons, alerts, highlights |
| `--color-gold-foil` | `#D4AF37` | Cover debossing, metallic foil finish in 3D shader |

## 3. Typography Hierarchy

- **Serif (Headings & Memory Titles)**: `Newsreader` / `Playfair Display` / `Georgia` for editorial warmth.
- **Sans (Interface & Data)**: `Inter` / `Geist` / system UI for crisp readability at small sizes.
- **Mono (Timestamps & Preflight Specs)**: `JetBrains Mono` / monospace for technical print parameters and coordinates.
